Operator's Guide, User Manual & Help Center

Complete step-by-step instructions on setting up, using, and troubleshooting your Universal AI-Native Development Architecture across Cursor, Claude Code, and Codex.

Chapter 1

60-Second Quickstart Guide

You can bootstrap the agent-folders system into any new or existing project in seconds. Choose the method that best matches your workflow:

Method A: npx Initialization (Recommended)

Open your terminal, navigate to your target project folder, and run:

# 1. Initialize canonical folders, policies, and adapters:
npx agent-folders init

# 2. Run system health & token budget check:
npx agent-folders doctor

# 3. Scaffold your first application:
npx agent-folders scaffold full-stack-app client-portal

Method B: One-Line Shell / cURL Installer

If you don't have Node or npm globally installed, run this single shell command:

curl -fsSL https://raw.githubusercontent.com/rjbizsolution23-wq/agent-folders/main/install.sh | bash

Method C: GitHub 1-Click Template

Click Use this template on GitHub to spawn an immediate clean repository under your own account.

Chapter 2

The 6-Level Progressive Context Protocol

The single most important principle in agent-folders is Progressive Context Disclosure. When you instruct an AI coding agent, never ask it to "read the entire repository." Doing so pollutes the context window and triggers hallucinated code.

The Golden Rule: AI agents start by reading only Level 0 (AGENTS.md, sub-300 tokens). They read deeper levels only when their specific task requires it.
Level Artifact / Path Token Size When to Load
Level 0 AGENTS.md ~287 tokens Every session start. Acts as the navigational compass.
Level 1 .ai/policies/*.md ~200 tokens each On-demand: Read engineering.md before writing code, security.md before modifying auth, testing.md before writing tests.
Level 2 .ai/context/*.md ~500 tokens During architecture planning or cross-module refactoring.
Level 3 .ai/skills/<name>/SKILL.md ~400 tokens On trigger: Load debugging when tests fail, planning when starting a multi-file feature.
Level 4 projects/<app>/src/* Variable Surgical target files: Only the specific files being modified.
Level 5 .ai/context/decisions-log.md ~300 tokens Historical edge cases: Consulted only when resolving past architectural ambiguities.
Chapter 3

Tool Configuration: Cursor, Claude Code, and Codex

1. Using in Cursor IDE

Cursor automatically recognizes .cursorrules at the root of the project. The .cursorrules file directs Cursor to obey AGENTS.md and load rules from .ai/policies/.

Pro-Tip: In Cursor Chat composer (Cmd+I / Cmd+L), you can directly tag specific policies: @.ai/policies/engineering.md implement user authentication.

2. Using in Anthropic Claude Code

Claude Code automatically reads CLAUDE.md in your terminal. To invoke a specific skill with Claude Code, simply prompt:

Claude, activate .ai/skills/planning/SKILL.md to plan the database migration.

3. Synchronizing Rules (Zero Drift)

Whenever you update an engineering or security rule in .ai/policies/, run:

npx agent-folders sync

This automatically regenerates CLAUDE.md, .cursorrules, and GEMINI.md so all AI tools follow the exact same standards.

Chapter 4

Built-in Terminal Help & Diagnostic Oracle

You never have to search external documentation when stuck. agent-folders includes an interactive customer helpdesk built right into your CLI:

# Quick lookup on any topic:
npx agent-folders support tokens
npx agent-folders support cloudflare
npx agent-folders support cursor
npx agent-folders support scaffold

# Or launch the interactive guided Q&A wizard:
npx agent-folders support

Running npx agent-folders doctor executes a 5-point automated health inspection checking for missing canonical files, broken internal markdown links, and token budget overages.

Chapter 5

Troubleshooting & FAQ

Q: What if an agent ignores my coding rules?

A: Run npx agent-folders sync to verify your platform adapters match .ai/policies/. Then instruct the agent explicitly: "Read .ai/policies/engineering.md before writing code."

Q: Can I use this for non-TypeScript languages?

A: Yes. agent-folders is 100% language-agnostic. The policies, skills, context disclosure ladder, and adapters work identically for Python, Go, Rust, Java, or PHP.
