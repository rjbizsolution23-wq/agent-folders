# Project Context & Scope

## Vision
UANDA (Universal AI-Native Development Architecture) provides a cross-platform foundation for developing robust software systems, multi-agent workflows, and applications with minimal cognitive and token overhead.

## Core Capabilities
- **Cross-Platform Compatibility**: Supports Claude Code, OpenAI Codex, Cursor, and Gemini CLI through canonical sync.
- **Token Efficiency**: Prevents context bloating by progressive retrieval across 6 distinct levels.
- **Deterministic Reliability**: Automated validation of architecture, drift detection, and reproducible scaffolding.
