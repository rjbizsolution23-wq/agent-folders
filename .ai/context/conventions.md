# Coding & Naming Conventions

## File & Directory Naming
- Directories: lowercase kebab-case (e.g., `feature-auth`, `data-pipeline`).
- Markdown Docs: lowercase kebab-case (e.g., `engineering.md`, `release.md`).
- Scripts: lowercase kebab-case (e.g., `validate-architecture.py`).
- TypeScript files: camelCase or kebab-case matching standard framework idioms.

## Git Commit Format
Use Conventional Commits:
- `feat(scope): add new capability`
- `fix(scope): resolve bug`
- `docs(scope): update documentation`
- `refactor(scope): optimize internal logic`
- `test(scope): add verification tests`
