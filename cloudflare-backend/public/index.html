Answers to Common Questions

Frequently Asked Questions

Clear, direct answers to help you get the most out of agent-folders.

How does agent-folders cut token costs by 70%?

Traditional AI setups force models to ingest entire directory trees and large README files on every prompt. agent-folders enforces a 6-Level Progressive Context Ladder where the initial prompt loads only a sub-300-token pointer (AGENTS.md). Policies, skills, and schemas are retrieved strictly just-in-time when the task requires them.

Does this require switching away from Cursor or Claude Code?

Not at all. agent-folders is not a new editor—it is an architectural standard designed to make Cursor, Claude Code, OpenAI Codex, and Gemini CLI operate with 10x higher reliability. You continue using your favorite tools.

Can I install this into an existing codebase?

Yes. Run npx agent-folders init in your terminal. It safely injects the canonical .ai/ configuration and platform adapters without modifying or overwriting your existing code.

What happens when platform rules drift?

You run npx agent-folders sync. This automatically reads your canonical rules from .ai/policies/ and regenerates CLAUDE.md, .cursorrules, and GEMINI.md so all AI tools follow the exact same guidelines.
